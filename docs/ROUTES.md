# Calm Spaces Route Map

## Public

- `/` — homepage
- `/about` — mission and CALM philosophy
- `/features` — feature overview
- `/resources` — resource library
- `/privacy` — privacy policy
- `/terms` — terms of service
- `/contact` — support information

## App

- `/dashboard` — role-aware home
- `/mood` — mood tracking and insights
- `/journal` — private journal
- `/wellness` — breathing, grounding, focus, gratitude, movement
- `/ai-assistant` — support assistant
- `/buddy-connect` — peer support
- `/experts` — professional support and booking
- `/appointments` — scheduled sessions
- `/profile` — profile details
- `/settings` — account, privacy, notifications, accessibility
- `/sos` — emergency and crisis resources

## Admin

- `/admin` — admin dashboard
- `/admin/users` — role management
- `/admin/resources` — resource moderation
