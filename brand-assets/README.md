# Official brand assets required

This directory intentionally contains no generated logo replacements.

Required approved assets:

- `calm-spaces-logo.svg`
- `calm-spaces-logo-horizontal.svg` when officially supplied
- `calm-spaces-logo-mark.svg` when officially supplied
- `sgt-university-logo.svg`
- approved team photographs
- approved campus/program photography
- approved app screenshots

Source requirement: each asset must be supplied by or traced to an official C.A.L.M Spaces, CEAPS, or SGT University source before publishing. Until then, the UI must use a clearly marked fallback and must not call it the official logo.
