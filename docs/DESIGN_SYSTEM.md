# Calm Spaces Design System

## Design intent

The platform should feel calm, trustworthy, human, and private. It should not look like a generic SaaS health dashboard or a neon mental-health app.

## Color system

- Background: warm ivory
- Surface: soft white
- Primary: deep indigo / violet for trust and calm
- Secondary: sage green for support and recovery
- Accent: muted terracotta for warmth
- Success: green
- Warning: amber
- Error: rose
- Text primary: near-black
- Text secondary: slate gray
- Border: soft neutral

## Typography

- Display: large editorial headings for landing pages
- H1-H3: calm, readable sans
- Body: neutral and spacious
- Captions: subtle but legible

## Layout rules

- generous whitespace
- clear hierarchy
- accessible contrast ratios
- mobile-first card layouts
- desktop multi-column data surfaces

## Components

- Buttons
- Cards
- Inputs
- Textareas
- Badges
- Tabs
- Modal / sheet
- Sidebar navigation
- Data table
- Charts
- Empty states
- Safety banner

## Accessibility guidance

- focus outlines required
- keyboard navigation for navigation and dialogs
- no information conveyed by color alone
- respect reduced motion
- touch targets at minimum 44x44px

## Responsive patterns

- public marketing pages scale naturally
- authenticated app uses sidebar on desktop and bottom nav on mobile
- chart content reflows without horizontal scrolling
